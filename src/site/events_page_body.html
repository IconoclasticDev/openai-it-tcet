Neural Networks from Scratch

Academic Year 2025-26
IT Department Lab, TCET Campus

In-depth technical seminar covering line-by-line PyTorch & NumPy implementation of forward pass matrix multiplications, backpropagation calculus, and loss optimization for feed-forward neural networks.

Key Highlights & Topics
  • • Matrix Calculus & Backpropagation: Mathematical derivation of chain rule gradients for weights and biases.
  • • PyTorch vs NumPy: Building custom autograd engines vs standard PyTorch nn.Module abstractions.
  • • Activation Functions: Comparative analysis of ReLU, GELU, and Sigmoid saturation regions.

Auditorium / IT Conference Hall, TCET

Architectural breakdown of multi-agent LLM systems, function calling, tool use integration, memory retention strategies, and autonomous agent loops.

Perceptron Architecture & Foundations

Academic Year 2025-26
Online / Virtual Interactive Session

Fundamental mathematical webinar introducing single-layer perceptrons, linear decision boundaries, weight vector updates, and activation functions.

Key Highlights & Topics
  • • Single-Layer Perceptron Math: Mathematical proof of linear separability and perceptron convergence theorem.
  • • Decision Boundaries: Geometric interpretation of hyperplanes in high-dimensional feature spaces.
  • • Interactive Code Demo: Live Python implementation of Frank Rosenblatt's perceptron algorithm.
